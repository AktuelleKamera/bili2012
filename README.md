# BiliClassic Web

哔哩哔哩2012版播放页的本地恢复。页面和Flash播放器来自2012年Web Archive的存档，后端为Node.js。

## 如何运行本项目？

需要Node.js 18以上版本。

双击`start.bat`，或在`demo`目录执行：

```bat
npm install
npm start
```

默认地址：`http://localhost:8080/`

服务端口：

- `8080`：网页、图片、视频和弹幕代理
- `88`：弹幕Socket，用于当前观众计数

## 配置

以下环境变量都有默认值，本地运行一般不用改：

- `PORT=8080`：网页服务端口
- `PUBLIC_ORIGIN=http://localhost:8080`：分享链接和启动日志使用的地址
- `PUBLIC_HOST=localhost`：无法从请求里取到 Host 时使用的备用主机名
- `DANMAKU_PORT=88`：弹幕 Socket 端口
- `SESSION_SECRET=`：登录态加密密钥，可选；不填会自动生成本地密钥文件

播放器使用相对地址，接口地址也会按当前访问的域名和端口生成，所以换端口或局域网访问不需要改 SWF。`PUBLIC_ORIGIN`只影响分享链接和日志，不是播放器的连接地址。

## 局域网访问

服务默认监听所有网卡。其他设备直接访问`http://本机局域网IP:8080/`，Windows防火墙需要放行`8080`和`88`端口。

## 页面

- 2012首页：`/`或`/2012`
- 视频页：`/av<号>`、`/bv/<BV号>`
- 搜索结果：`/search?keyword=<关键词>`
- 番剧页：`/bangumi/ep<号>`
- 用户空间：`/space/<mid>`
- 个人资料：`/space/<mid>/info`
- 收藏夹：`/favlist`（登录后查看自己的收藏夹和收藏视频）
- 播放历史：`/history`（登录后查看自己的播放记录）
- 直接播放器：`/player`
- 安卓客户端页：`/html/android.html`
- iOS客户端页：`/html/ios.html`
- 名人堂：`/html/cele.html`
- 补档认领处：`/html/userdel_list.html`
- Ruffle模式：在2012页面后加`?ruffle=1`

## 登录

打开`/login`，在“ID或E-Mail”填手机号，点“登录”即可发送短信。验证码填到下方验证码输入框，再点“登录”，“你的密码”留空。

注册按钮只有装饰作用，接口已失效。

## 已知问题

- 播放需要Flash Player。Ruffle能显示界面，但视频放不出来（
- 实时弹幕Socket需要放行88端口。
- 已删除或不公开的视频会返回`62002`。
- 未登录时视频清晰度通常最高720P。
- 2012版播放器播放结束后底部播放按钮不会重播，需要刷新页面。
